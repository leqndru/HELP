Como Jogar
O objetivo é limpar o campo sem detonar nenhuma bomba.
Clique com o botão esquerdo para revelar um quadrado. O número indica quantas minas o cercam.
Clique com o botão direito para marcar uma mina suspeita com uma bandeira.
Use a marca de interrogação se não tiver certeza de um local.
